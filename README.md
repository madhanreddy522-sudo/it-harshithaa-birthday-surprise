# Harshithaa Birthday Website — tap-to-open edition

This version removes the arrow completely. The intro uses a normal **Tap to Open Your Surprise** button. It keeps the romantic design, seven personal photos, synthesized upbeat party music, photo memories with quotes, and birthday video.

## Publish on GitHub Pages
1. Create a new public repository.
2. Upload the contents of this folder to the repository root (upload the files themselves, not this ZIP).
3. Commit the files to the `main` branch.
4. Open Settings → Pages; choose **Deploy from a branch**, `main`, and `/(root)`, then Save.
5. Wait a few minutes for GitHub Pages to publish.

Files: `index.html`, `photo1.jpg` through `photo7.jpg`, `birthday-wishes.mp4`, and `video-poster.jpg`.

Note: the repository is public, so uploaded photos and video can be viewed by anyone.
